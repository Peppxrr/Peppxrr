# Hi, I'm Pepper.

I mostly make software because I want something that doesn't exist yet, or because the existing options don't quite do what I want.

I wouldn't call myself much of a developer. Usually I come up with an idea, beat an LLM over the head with it until it does what I want, and then spend way too long figuring out why something doesn't work. I've learned a fair bit along the way, but I'm still figuring a lot of things out.

I like open-source software and Linux, and I'm trying to make my projects work on both Windows and Linux where possible. Linux support can be a pain but I'd like there to be fewer reasons for people to feel stuck on Windows.

## Projects

### [Shard](https://github.com/Peppxrr/Shard)

A game clipping and recording app I'm working on as an alternative to things like Medal and Outplayed, without needing an account or uploading clips anywhere.

It has instant replays, automatic game detection, separate audio tracks, a clip library, and a built-in editor. You can also export clips to fit upload limits without having to mess around with another editor.

Windows is the main platform for now. There's a Linux build too, but it's still experimental and has plenty of things that need fixing.

### [Avatar Cloth Fit](https://github.com/Peppxrr/avatar-cloth-fit)

A Blender add-on I started because fitting clothing to edited VRChat avatars can be a complete headache.

It has tools for shaping clothes around an avatar, transferring and cleaning up weights, and checking how clothing deforms in different poses. I'm also trying to make it behave with awkward stuff like straps, belts, and separate pieces of clothing. It still needs manual work in some cases, but that's part of why I'm making it.

There's a release available if you want to try it. Don't read too much into the version number; the LLMs got a little carried away with that.

[Source](https://github.com/Peppxrr/avatar-cloth-fit) · [Downloads](https://github.com/Peppxrr/avatar-cloth-fit/releases/latest) · [Issues](https://github.com/Peppxrr/avatar-cloth-fit/issues)
